# 색칠놀이 (Coloring App)

아이용 컬러링 웹앱. 빌드 도구 없이 Vanilla JS(ES Modules)로 작성한다.

## 돌려보기

ES Modules와 서비스 워커를 쓰므로 `file://`로는 열리지 않는다. 로컬 서버가 필요하다.

```bash
cd ColoringApp && python -m http.server 8000
```

http://localhost:8000 을 연다. 갤럭시 탭에서는 같은 와이파이에서
`http://<PC주소>:8000`으로 접속한 뒤 "홈 화면에 추가"를 하면 전체화면 앱이 된다.

## 상태

명세서 13장 1~10단계와 15장 11단계까지 전부 구현되어 있다.

| 단계 | 내용 |
|---|---|
| 1 | 화면 전환, 가로 레이아웃, 도안 JSON, 그리드 |
| 2 | 레이어 4장, 좌표 변환, 팔레트 8색, 굵기 3단계 |
| 3 | 되돌리기 / 다시하기 / 다 지우기(1초 길게) |
| 4 | 영역 맵(Web Worker), 선 밖 안 나가기, 페인트 채우기 |
| 5 | 붓·펜·색연필·크레파스·지우개 + 필압 |
| 6 | 오터치 방지 (멀티터치 취소, S펜 우선) |
| 7 | 자동 저장·이어하기(IndexedDB), 갤러리 내려받기 |
| 8 | 옵션 패널, HSV 색상 선택기, 최근 색 |
| 9 | PWA (manifest + service worker), 상대 경로 |
| 10 | 효과음(WebAudio), 완료 연출, 내 작품 모아보기 |
| 11 | 착한 일 토큰, 부모 모드, 암호, 특별 도구 |

## 도안 넣기

`assets/drawings/`에 2048×2048 PNG를 넣고 `data/drawings.json`에 항목을 더한다.

```json
{
  "id": "whale",
  "title": "고래",
  "lineart": "assets/drawings/whale.png",
  "thumbnail": "assets/drawings/whale_thumb.png",
  "cost": 0,
  "palette": ["#4A90D9", "...8색..."]
}
```

- `palette`는 정확히 8색
- `cost`가 1 이상이면 토큰으로 여는 잠긴 도안이 된다
- 도안을 더한 뒤에는 `sw.js`의 `SHELL` 목록과 `CACHE` 버전을 함께 갱신한다

도안 자체의 규격(흰 배경, 검은 굵은 선, 닫힌 영역)은 명세서 14장을 따른다.
선이 끊겨 있으면 페인트가 옆 영역으로 새어 나간다.

들어 있는 도안은 전부 실제 도안이다. 임시 플레이스홀더는 없다.

새 그림을 넣을 때는 2048×2048이 아니어도 된다. 정사각형이기만 하면
`scripts/import_drawings.py`가 2048로 올리고 임계값 160으로 순수 흑백을
만든 뒤 썸네일까지 뽑는다.

## 손대면 되는 곳

- `js/config.js` — 굵기, 브러시 성질, 되돌리기 한도, 영역 맵 임계값, 토큰 기본값
- `js/icons.js` — 도구 아이콘 (이모지는 기기마다 달라서 SVG로 직접 그린다)
- `css/style.css` — 색과 크기는 `:root` 변수에 모여 있다

## 메모

- **되돌리기는 바뀐 영역만 저장한다.** 전체 스냅샷은 2048²×4 = 16MB라
  30단계면 메모리가 터진다. 단계 수(30)와 총 바이트(64MB) 중 먼저 걸리는
  쪽에서 오래된 것부터 밀어낸다.
- **애니메이션의 마무리를 rAF에만 맡기지 않는다.** 화면이 가려지면 rAF가
  멈춘다. 길게 누르기와 페인트 퍼짐은 실제 타이머로 받쳐 둔다.
- **그라데이션을 `transparent`로 끝내지 않는다.** 그건 "투명한 검정"이라
  캔버스가 RGB까지 검정으로 보간해 붓 가장자리가 거뭇해진다.
  색은 단색으로 깔고 알파만 따로 깎는다.
